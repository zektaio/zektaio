# Zekta

We're building infrastructure for anonymous blockchain transactions using zero-knowledge proofs.

The core idea: you can prove you're authorized to do something without revealing who you are. No wallet addresses stored, no transaction history linked to your identity.

## How it works

Zekta uses Semaphore Protocol to generate cryptographic identities. Users prove group membership through ZK proofs, then execute transactions anonymously on Solana. The server verifies proofs and relays transactions - we never see your wallet address.

This opens up possibilities like anonymous domain purchases, private gift card orders, and unlinkable crypto swaps. But the real potential is what developers will build on top of it.
